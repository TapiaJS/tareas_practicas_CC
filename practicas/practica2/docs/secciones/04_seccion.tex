\section{Ejercicio 4}

\begin{tcolorbox}[enunciado]
Ejecutar su implementación con al menos 3 ejemplos de diferentes tamaños, suficientemente grandes. \\
Para cada ejemplar:
\begin{itemize}
    \item generar 3 certificados diferentes (con el programa del inciso anterior).
    \item proponer al menos 2 certificados interesantes (por ejemplo, que considere una respuesta parcialmente correcta, que contenga cierta redundancia, etc).
\end{itemize}
\end{tcolorbox}

\subsection{Certificados}
Las letras de cada certificado, hacen alusión al tipo de certificado que es.
Si contiene una V es que es válido.
Si contiene una F es que es inválido.
El interesante del ejemplar 1, es un certificado modificado. Se borro el bit inical de dicho certificado, a la hora de querer ejecutarlo con el verificador, el verificador lo rechaza.
El interesante del ejemplar 2, se forzó al generador de certificados, a que imprimeran puros 0, por ende, es inválido, porque no alcanza la meta impuesta.
El ejemplar 3 fue forzado para que siempre diera falso, se generó de manera aleatoria, y los ultimos 16 bits, se cambiaron por puros unos, haciendo que la ganancia fuera inalcanzable con el modelo actual.
Entonces al generar 3 certificados, todos dieron falso.
