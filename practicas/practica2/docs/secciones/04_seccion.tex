\section{Ejercicio 4}

\begin{tcolorbox}[enunciado]
Ejecutar su implementación con al menos 3 ejemplos de diferentes tamaños, suficientemente grandes. \\
Para cada ejemplar:
\begin{itemize}
    \item generar 3 certificados diferentes (con el programa del inciso anterior).
    \item proponer al menos 2 certificados interesantes (por ejemplo, que considere una respuesta parcialmente correcta, que contenga cierta redundancia, etc).
\end{itemize}
\end{tcolorbox}
